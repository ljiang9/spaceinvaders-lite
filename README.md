# spaceinvaders-lite

迷你太空入侵者克隆：40×22 文本战场，4×8 入侵者阵型左右横移、碰边下沉，
玩家左右移动开火，入侵者向下还击，4 座护盾可挡子弹。纯标准库，无第三方依赖。

## 玩法

- `^` 是你（最底行），`V` 是入侵者，`|` 是你的子弹，`!` 是敌方子弹，`#` 是护盾
- 入侵者按节拍横移，碰到边缘就反转并下降一行；数量越少节拍越快（致敬原版加速机制）
- 入侵者降到你的行 = 游戏结束；3 条命；全灭入侵者 = 胜利

## 用法

```bash
python3 -m spaceinvaders_lite              # 回合制交互：l/r 移动，s 射击，q 退出
python3 -m spaceinvaders_lite --auto        # 自动演示（AI 瞄准+躲子弹）
python3 -m spaceinvaders_lite --auto --seed 42 --frames 1000
python3 -m spaceinvaders_lite --auto --verbose  # 每 100 帧打印一次战场
```

## 设计取舍

- 入侵者移动是"节拍制"（每 3/2/1 帧走一格）而非每帧一格，还原原版手感，
  也让 `--auto` 的拦截预测更稳定
- 每列只有最底下的入侵者会开火（经典规则），避免弹幕过密
- 玩家同时只能有一发子弹在膛（经典限制）
- `--auto` 的 AI：前向模拟阵型（含节拍、碰边反转、下沉）算出拦截点，
  锁定单个目标直到击杀；敌方子弹 2 帧内逼近才躲。演示 600 帧通常能击杀
  5–20 个，不是无敌玩家

## 真实验证记录

- `python3 -m py_compile spaceinvaders_lite.py __main__.py` 通过
- 8 项单元测试全过：子弹命中（击杀+10 分）、入侵者到底线判负、
  玩家被击中掉命、碰边反转+下沉、非节拍帧不动、护盾挡子弹、
  全灭判胜、节拍随数量加速、每列仅最下开火
- `--auto --seed 1/7/42`：全部正常结束（如 seed 7：击杀 22，得分 220）
- 回合制交互管道输入（`s`/`q`）正常

## 已知局限

- 无实时键盘输入：交互是"每行一个命令"的回合制，不是实时动作游戏
- `--auto` AI 不完美：不会预判护盾挡路，偶尔会被流弹击中
- 无最高分存档、无关卡/难度选项
- 需要 Python 3.10+
